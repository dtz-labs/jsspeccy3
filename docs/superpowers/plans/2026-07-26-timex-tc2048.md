# Timex TC2048 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Timex Computer 2048 as a selectable machine in JSSpeccy 3, with all three Timex SCLD video modes (dual display file, hi-colour 8x1, hi-res 512x192) including mid-frame mode switching.

**Architecture:** The WebAssembly core gains a `timexVideoEnabled` flag, a port `0xFF` decode, a Timex branch in `updateFramebuffer()`, and a mode-change log appended to the frame buffer. The renderer gains a 640x240 backing store for Timex machines and a hi-res decoder. Every change is behind a machine-type guard so 48K/128/Pentagon behaviour stays bit-identical.

**Tech Stack:** AssemblyScript (compiled to WASM via `asc`), a custom line-based preprocessor (`generator/gencore.js`), plain ES modules for the runtime, webpack for bundling, Node for tests.

## Global Constraints

- Target an upstream PR to `gasman/jsspeccy3`: the diff stays **additive**, guarded by machine type. No refactor of the 16 KB paging model in this phase.
- Machine type constant is `2048` (existing: 48, 128, 5 = Pentagon, 1212 = test).
- TC2048 ROM occupies **16 KB page 14**. Phase 2 renumbers pages; do not shape phase 1 around that.
- `FRAME_BUFFER_SIZE` becomes `0x6a00`; the pixel log at `0x0000..0x65ff` keeps its existing format exactly.
- Mode log lives at frame-buffer offset `0x6600`, max **255** records of 4 bytes, terminated by `0xffff`.
- TC2048 timing is identical to 48K: `frameCycleCount = 69888`, `buildScreenEventsTable(14335, 224, 0xfc)`, `buildContentionTable(14335, 224, ...)`.
- SCLD mode bits are independent enables: bit 0 = display file, bit 1 = hi-colour, bit 2 = hi-res, **bit 2 wins over bit 1**.
- Hi-res colour (starting assumption, to be confirmed against ZEsarUX):
  `paperIndex = 8 + ((portFF >> 3) & 7)`, `inkIndex = 8 + (((portFF >> 3) & 7) ^ 7)` — both bright.
- **Preprocessor constraint:** `gencore.js` rewrites `name[index]` with the regexp `/(\w+)\s*\[([^\]]+)\]/g`. An index expression must **never contain a `]`**, so no nested array lookups. Assign to a local `const` first, exactly as the existing code does.
- Never name a local the same as an `#alloc` array or `#const` — `gencore.js` does a blanket `\w+` substitution over every expression.

Replace the body of `updateFramebuffer` with:

```
function updateFramebuffer():void {
    /* process all of the screen bytes that are due up to the current tstate */
    const screenBaseAddr:u32 = screenPageIndex << 14;

    if (timexVideoEnabled) {
        updateFramebufferTimex(screenBaseAddr);
        return;
    }

    // end marker is 0xffffffff, which will always be greater than t
    while (screenEvents[screenEventPointer] <= t) {
        const addressWord:u32 = screenEvents[screenEventPointer + 1];
        if (addressWord == 0xffffffff) {
            frameBuffer[framebufferIndex++] = borderColour;
            floatingBusValue = 0xff;
        } else {
            const screenAddr:u32 = screenBaseAddr | (addressWord & 0xffff);
            const attributeAddr:u32 = screenBaseAddr | (addressWord >> 16);
            frameBuffer[framebufferIndex++] = machineMemory[screenAddr];
            frameBuffer[framebufferIndex++] = machineMemory[attributeAddr];
            frameBuffer[framebufferIndex++] = machineMemory[screenAddr + 1];
            floatingBusValue = machineMemory[attributeAddr + 1];
            frameBuffer[framebufferIndex++] = floatingBusValue;
        }
        screenEventPointer += 2;
    }
}

function updateFramebufferTimex(screenBaseAddr:u32):void {
    /* Timex SCLD screen modes. Mode bits are independent enables:
    bit 0 selects the display file, bit 1 enables hi-colour (8x1 attributes),
    bit 2 enables hi-res 512x192, and bit 2 wins over bit 1.

    Hi-colour and hi-res fetch identical addresses - only the renderer's
    interpretation differs - so they share a branch here. */
    const mode:u8 = timexScreenMode & 0x07;
    while (screenEvents[screenEventPointer] <= t) {
        const addressWord:u32 = screenEvents[screenEventPointer + 1];
        if (addressWord == 0xffffffff) {
            frameBuffer[framebufferIndex++] = borderColour;
            floatingBusValue = 0xff;
        } else if (mode & 0x06) {
            const loAddr:u32 = screenBaseAddr | (addressWord & 0xffff);
            const hiAddr:u32 = loAddr + 0x2000;
            frameBuffer[framebufferIndex++] = machineMemory[loAddr];
            frameBuffer[framebufferIndex++] = machineMemory[hiAddr];
            frameBuffer[framebufferIndex++] = machineMemory[loAddr + 1];
            floatingBusValue = machineMemory[hiAddr + 1];
            frameBuffer[framebufferIndex++] = floatingBusValue;
        } else {
            const displayFile:u32 = (mode & 0x01) ? 0x2000 : 0;
            const screenAddr:u32 = screenBaseAddr | (displayFile + (addressWord & 0xffff));
            const attributeAddr:u32 = screenBaseAddr | (displayFile + (addressWord >> 16));
            frameBuffer[framebufferIndex++] = machineMemory[screenAddr];
            frameBuffer[framebufferIndex++] = machineMemory[attributeAddr];
            frameBuffer[framebufferIndex++] = machineMemory[screenAddr + 1];
            floatingBusValue = machineMemory[attributeAddr + 1];
            frameBuffer[framebufferIndex++] = floatingBusValue;
        }
        screenEventPointer += 2;
    }
}
```

Note the local names `loAddr`, `hiAddr`, `displayFile`, `mode` — none collides with an `#alloc` array or `#const`, and no array index contains a `]`.

```
    /* Record that `mode` takes effect at byte `index` of the pixel log.
    Silently drops entries past MODE_LOG_MAX_ENTRIES; a per-scanline effect
    needs at most 192, so the cap cannot be hit by legitimate software. */
    if (modeLogCount >= MODE_LOG_MAX_ENTRIES) return;
    frameBuffer[modeLogPointer] = u8(index & 0xff);
    frameBuffer[modeLogPointer + 1] = u8(index >> 8);
    frameBuffer[modeLogPointer + 2] = mode;
    frameBuffer[modeLogPointer + 3] = 0;
    modeLogPointer += 4;
    modeLogCount++;
}

function resetModeLog():void {
    modeLogPointer = MODE_LOG_OFFSET;
    modeLogCount = 0;
    writeModeLogEntry(0, timexScreenMode);
}

function terminateModeLog():void {
    /* Terminator does not advance the pointer, so a later entry overwrites it. */
    frameBuffer[modeLogPointer] = 0xff;
    frameBuffer[modeLogPointer + 1] = 0xff;
    frameBuffer[modeLogPointer + 2] = 0;
    frameBuffer[modeLogPointer + 3] = 0;
}
```
